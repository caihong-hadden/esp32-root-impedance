# ESP32-S3 植物根系损伤阻抗探测

> 用阻抗谱判断植物根系是否受损：ESP32-S3 上的微弱信号采集与复数域分析。

## 它解决什么

植物根系受损后，组织的含水量与离子浓度会变，反映在**土壤阻抗的幅值与相位**上。难点是信号极弱，且被工频干扰与开关噪声压着——测得到波形不等于测得准阻抗。

## 关键实现

- **DSP 滤波管线**：多级滤波（去直流 → 带通 → 平滑）后再做复数变换，把幅值与相位分离，而不是只看幅值
- **任务切分**：采集、运算、上报分属不同任务并设优先级，采集线程不允许被运算阻塞
- **标定**：用已知阻抗做基准校准，消除电极与线缆带来的固定偏移
- **诊断**：按阻抗谱形态判定受损等级，输出可直接读取的结论

> 本仓库只含固件源码（信号处理、任务调度、采集与标定模块）。项目申报材料、演示文稿与合作文档涉及第三方信息，未纳入。

## 技术栈

- **MCU**：ESP32-S3（双核，FreeRTOS）
- **信号链**：DAC 激励 → ADC 采集 → 数字滤波 → 复数域变换 → 阻抗特征
- **语言**：C
